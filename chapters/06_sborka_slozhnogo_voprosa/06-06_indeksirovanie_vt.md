# § 6.6. Индексирование временной таблицы

## Открытие

Временная таблица — настоящие данные, сложенные и лежащие рядом. Значит, по ней
придётся искать: соединять с другими таблицами, отбирать по условию.

```запрос,песочница
ВЫБРАТЬ
    Товары.Ссылка КАК Товар,
    Товары.Наименование КАК Наименование
ПОМЕСТИТЬ Список
ИЗ
    Справочник.Товары КАК Товары
ГДЕ
    НЕ Товары.ЭтоГруппа
ИНДЕКСИРОВАТЬ ПО
    Товар
;
ВЫБРАТЬ
    Список.Наименование,
    Остатки.КоличествоОстаток КАК Остаток
ИЗ
    Список КАК Список
        ЛЕВОЕ СОЕДИНЕНИЕ
            РегистрНакопления.ТоварыНаСкладах.Остатки КАК Остатки
        ПО Список.Товар = Остатки.Товар
```

Новое здесь одно слово — `ИНДЕКСИРОВАТЬ ПО`.

## Зачем таблице указатель

Соединение спрашивает: «а есть ли в этой таблице строка с таким товаром?» — и
спрашивает столько раз, сколько строк во второй таблице.

Без указателя ответ ищут перебором: пройти таблицу и посмотреть каждую строку.
С указателем — сразу в нужное место.

```текст
  без индекса   перебрать все строки
                и сравнить каждую

  по индексу    открыть на нужном месте
```

Разница не видна на десяти строках и решает всё на сотне тысяч.

У таблиц базы часть указателей есть заранее: платформа строит их по описанию в
конфигурации — по измерениям регистров, по регистратору, по реквизитам, для
которых индекс заказан. Но и там указатель есть не по любому полю: по
неиндексированному реквизиту поиск идёт тем же перебором.

**У временной таблицы указателей нет вовсе:** она создана только что, в
конфигурации её не описывали, и по какому полю по ней будут искать, никто
заранее не знал.

## Как записывают

`ИНДЕКСИРОВАТЬ ПО` ставят в конце запроса, который создаёт таблицу, и
перечисляют после него поля.

```текст
  ВЫБРАТЬ …
  ПОМЕСТИТЬ Список
  ИЗ …
  ГДЕ …
  ИНДЕКСИРОВАТЬ ПО
      Товар
```

Одно требование документация называет прямо: **поля, по которым строится
указатель, должны быть в списке выборки.** Индексировать то, чего в таблице
нет, нельзя.

## По каким полям

Ответ следует из того, зачем указатель нужен: по тем полям, **по которым эту
таблицу потом ищут**.

| дальше в пакете | что индексировать |
|---|---|
| соединение по полю | поле соединения |
| отбор `ГДЕ` по полю | поле отбора |
| таблицу читают целиком | ничего |

Последняя строка не описка. Если временная таблица нужна целиком и без поиска —
скажем, её просто выводят, — указатель ей ни к чему: строить его тоже работа.

## Чем платят

Указатель складывают в момент создания таблицы. Это время и место, потраченные
заранее, в расчёте на то, что поиск окупит.

Отсюда мера: **индексируют то, по чему ищут, и не индексируют остальное.**
Указатель по всем полям подряд — не осторожность, а лишняя работа, выполненная
дважды: сначала на укладке, потом впустую.

## Что это меняет для чтения

У временной таблицы в чужом пакете проверяют пару «создание — использование»:

- есть ли `ИНДЕКСИРОВАТЬ ПО` и по каким полям;
- по каким полям её соединяют и отбирают дальше;
- сходятся ли эти два списка.

Не сошлись — есть о чём спросить. Индекс по полю, которое дальше не ищут, — это
работа впустую. Соединение по полю без индекса — та самая причина, по которой
отчёт на большой базе идёт долго, а на демонстрационной летает.

## Главное

У временной таблицы, в отличие от таблиц базы, нет готовых указателей: она
создана только что, и по какому полю по ней будут искать, заранее неизвестно.
Указатель заказывают словами `ИНДЕКСИРОВАТЬ ПО` в конце запроса с `ПОМЕСТИТЬ`,
перечисляя поля, — и они обязаны быть в списке выборки. Индексируют то, по чему
таблицу потом ищут: поля соединений и отборов; таблице, которую читают целиком,
указатель не нужен. Платят за него временем и местом при укладке, поэтому
индекс по всему подряд — не осторожность, а лишняя работа. При чтении сверяют
два списка: по чему проиндексировали и по чему ищут.

## Упражнения

**Сверьте два списка.** Возьмите пакет параграфа и проверьте: поле в
`ИНДЕКСИРОВАТЬ ПО` — то же, по которому идёт соединение?

**Уберите индекс.** Выполните пакет без `ИНДЕКСИРОВАТЬ ПО`. Изменился ли ответ?
А что изменилось бы, будь в справочнике сто тысяч позиций?

**Найдите пропущенный.** Возьмите чужой пакет с временной таблицей и скажите,
не пропущен ли в нём указатель — и по какому полю.
