# § 7.3. Прямой обход и обход по группировкам

## Открытие

У запроса с итогами строки не равны друг другу: часть — подробности, часть —
итоги. Обойти такой результат можно двумя разными способами.

```bsl,платформа
Выборка = Результат.Выбрать(ОбходРезультатаЗапроса.Прямой);
Выборка = Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);
```

Разница между ними — не в скорости и не в удобстве, а в том, **что именно
окажется в выборке.**

## Прямой обход

Документация описывает его коротко: обход без группировок и иерархии.

Строки идут одна за другой — как они легли в результат. Никакой вложенности,
никаких уровней: плоский список, по которому проходят циклом `Пока
Выборка.Следующий()`.

Это то, чем мы пользовались до сих пор, и для запроса без итогов другого способа
не нужно.

## Обход по группировкам

`ПоГруппировкам` разбирает результат уровнями. Внешний цикл идёт по итоговым
строкам, а у каждой можно спросить её собственную выборку — с подробностями.

```bsl,платформа
Выборка = Результат.Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам);

Пока Выборка.Следующий() Цикл
    Сообщить(Выборка.Товар + ": " + Выборка.Продано);

    Подробности = Выборка.Выбрать();
    Пока Подробности.Следующий() Цикл
        Сообщить("    " + Подробности.Дата);
    КонецЦикла;
КонецЦикла;
```

Вложенный `Выбрать()` записан так же, как у результата, — те же параметры, — но
вызван у записи, и потому открывает следующий уровень относительно неё. Так дерево итогов из главы о свёртке
разворачивается в коде — уровень за уровнем.

## Чем записи отличаются друг от друга

У записи можно спросить, кто она такая.

| метод | что отвечает |
|---|---|
| `ТипЗаписи()` | подробность, итог по группировке, итог по иерархии, общий итог |
| `Группировка()` | имя группировки текущей записи |
| `Уровень()` | насколько глубоко запись лежит |

Пригождается это, когда одна процедура выводит и итоги, и подробности:
`ТипЗаписи()` отвечает, какое оформление брать, `Уровень()` — какой отступ.

```bsl,платформа
Если Выборка.ТипЗаписи() = ТипЗаписиЗапроса.ОбщийИтог Тогда
    // жирная строка внизу
КонецЕсли;
```

## Какие группировки обходить

У `Выбрать()` есть второй параметр — имена группировок.

```bsl,платформа
Выборка = Результат.Выбрать(
    ОбходРезультатаЗапроса.ПоГруппировкам, "Товар");
```

Документация задаёт два правила. Если параметр не указан — берётся следующая
группировка, названная в `ИТОГИ`. Если нужны детальные записи — передают пустую
строку.

Отсюда простая мысль: **обход опирается на то, что записано в запросе.** Имена
группировок в коде — те же самые, что стоят после `ИТОГИ … ПО`.

## Главное

Результат обходят двумя способами. Прямой обход даёт плоский список записей,
одну за другой, без группировок и иерархии — им и пользуются для обычного
запроса. Обход по группировкам разбирает результат уровнями: внешний цикл идёт
по итоговым строкам, а вложенный `Выбрать()` у записи открывает её подробности.
У каждой записи можно спросить `ТипЗаписи()` — подробность это или итог,
`Группировка()` — имя её группировки, `Уровень()` — глубину. Какие группировки
обходить, задаёт второй параметр `Выбрать()`; без него берётся следующая
группировка из `ИТОГИ`, а пустая строка означает детальные записи. Имена в
коде — те же, что в тексте запроса.

---

*Два обхода — два разных ответа на один результат. Значит, обход и текст запроса
обязаны быть согласованы, иначе часть ответа пропадёт незаметно.*

## Упражнения

**Разверните дерево.** Возьмите запрос с `ИТОГИ … ПО` и выведите его двумя
обходами. Сравните, что вывелось.

**Спросите запись.** Добавьте в цикл вывод `ТипЗаписи()` и `Уровень()`. Какие
значения встретились?

**Уберите имя.** Вызовите `Выбрать(ОбходРезультатаЗапроса.ПоГруппировкам)` без
второго параметра и объясните, какую группировку взяла платформа.
